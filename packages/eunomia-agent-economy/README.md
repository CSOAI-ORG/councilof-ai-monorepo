# eunomia-agent-economy

Bridge 4 — the **mitochondria**. AI agents can't hold bank accounts. `agent_wallet.py`
gives an agent (e.g. a MEOK NPC) a wallet: credits, a **reputation SBT credential graph**,
and **staking** so it can quote markets. An agent that exploits a counterparty is
**slashed** (stake burn). The NPC becomes a market participant — the MEOK gaming layer
trains financial agents.

> Measurement, not certification. Deterministic, offline.
