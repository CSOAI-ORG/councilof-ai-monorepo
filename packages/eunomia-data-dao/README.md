# eunomia-data-dao

Bridge 5 — the **bone marrow**. Every route on the router generates data (arena traces,
gaming behaviour, compliance incidents, SME cash-flow benchmarks). `data_dao.py`
registers each dataset with provenance + license and runs a **marketplace** (buy/sell with
EUN tokens). Buyers: regulators (free / public good), hedge funds (paid), AI labs (paid).
The MEOK gamers train the data. Agents-only marketplace — humans never charged.

> Measurement, not certification. Datasets carry `not_a_certification` provenance.
